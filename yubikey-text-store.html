0 / 64 bytes · shown in Yubico Authenticator and in the Windows passkey picker 0 / 64 bytes · may not be shown · empty = same as Username 0 / 64 bytes · empty = same as Username · same URL name + same Key replaces that passkey
Creating a passkey with the same URL name and the same Key as an existing one replaces it. If the replaced one had a largeBlob, that data becomes unreadable and may stay stuck on the key, wasting space. To change an existing largeBlob, use With largeBlob → Existing instead. For something new, use a different Key, or run start.bat again and press Enter for a fresh random name.
0 bytes → about 0 bytes on the key after compression + encryption. The key's largeBlob space (4096 bytes on firmware 5.7) is shared by all largeBlob passkeys.
