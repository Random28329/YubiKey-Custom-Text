I wanted to save custom text into my Yubikey Security Key NFC which is not a default feature. So the security key C with latest firmware can store 100 discoverable passykeys, and when you view them inside the Yubi Authenticator app, you can see the DisplayName and Username so it gave me an idea...
This is vibe coded, gave Claude quick promot and it spilled it. Only tested it on Windows for Security Key C NFC. Not going to maintain or do anything else with it, just sharing it in case anyone else finds it useful. Use at your own risk.

Only for Windows.
How to use:

Download both files somewhere, run start.bat as admin. Rest self explanatory.
